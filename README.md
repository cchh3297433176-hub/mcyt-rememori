# 忆海 (Rememori) — 主播掌机官方扩展记忆中枢

> 本仓库为 **《主播掌机》（MC YouTube模拟器）** 的官方独立沙盒记忆扩展模块（小手机内置 App ID: `rememori`，中文显示名：“忆海”）。
> 核心采用纯 TypeScript / 现代化 ESModule 开发，零后端、无原生动态库绑定，专为浏览器原生 WebView 环境提供高维语义向量检索、Reranker 重排序、基于真实对白凭据（Evidence）的多维长效记忆认知，以及独立的后台非阻塞事实提炼中枢。

---

## 1. 架构定位与最新演化

本项目为掌机主工程提供底层多维结构化记忆服务：
1. **轻量沙盒化独立运行**：在主工程中通过沙盒内嵌运行，支持双向安全通信协议，随开随走，无内存泄漏与历史栈卡死风险。
2. **多维结构化提炼中枢**：
   - 摒弃早期单一段落文本摘要，全面升级为五大维度：`[生活作息与偏好]`、`[彼此约定与清单]`、`[同伴印象与人际圈]`、`[情感暗流与当下心境]`、`[客观长效事实]`。
   - 严格遵循**第三人称具名铁律**：全部记录使用真实角色全称与“咩咩”，杜绝“他/她/它/对方”等模糊肉麻指代，防止角色认知错乱。
3. **协同主工程滑动窗口隐藏**：
   - 忆海负责后台沉淀长效记忆，主工程单人私聊发给大模型的上下文严格只取最新滑动窗口对白（8~12条），老聊天记录自动物理隐藏，封顶单次交互 Token 消耗。
4. **群记忆共通深度联动**：
   - 与群聊设置的 `共通开关 + 深度滑条(10~200条)` 无缝协同，角色在私聊中可根据需要以上帝视角阅读群内最近对白。

## 3. 核心功能与运作原理

### 3.1 复合维度追忆检索公式 (`src/memory.ts`)
综合召回评分公式：
```text
综合得分 = (余弦相似度 + 知识图实体共现权重 + 真实凭据强化分) × 深刻度(Salience) × 时间淡忘衰减系数
```
- **余弦语义相似度 (`src/similarity.ts`)**：支持 BAAI/bge-m3 等模型高维向量归一化点积计算。
- **实体共现网络 (`src/extract.ts`)**：提取人名专名赋予关联加权。
- **真实凭据（Evidence）机制 (`src/evidence.ts`)**：每条记忆绑定产生该记忆的真实对白原话（`rawQuote`）与时间戳。

### 3.2 多维结构化提炼规范 (`site/prompts/chat.js`)
提炼提示词按需输出规范化标签：
- `[生活习惯]`：作息时间、熬夜/早起偏好、饮食口味、雷区与游戏习惯；
- `[约定事项]`：双方口头承诺、未来待办计划（标记为待履约）；
- `[同伴印象: 目标同伴名]`：当前角色对其他群友或NPC的看法与印象；
- `[心境暗流]`：角色内心真实心态演变（暗自吃醋、依赖、傲娇嘴硬等）；
- `[长效事实]`：客观重大事件与进展。

### 3.3 界面交互质感 (`site/index.html` & `main.js`)
- **首页**：微信小程序微光渐变，一行双列 62px 大圆形高清头像卡片，右上角绿底白字记忆数量角标，居中角色全称。
- **二级殿堂**：点击角色下钻独立多维记忆殿堂，分类分流展示各个记忆卡片。
- **视觉去 Emoji**：摒弃杂乱 Emoji 装饰，底栏提炼按钮采用微光素雅磨砂玻璃卡片风格，操作温润克制。

## 4. 开发与构建

```bash
# 1. 安装依赖
npm install

# 2. 运行单元测试
npm test

# 3. 编译输出核心库
npm run build
```

主工程构建 APK 时会自动从本仓库拉取 `site/` 资源集成至 assets 中，实现纯单机无网络依赖的极速体验。
